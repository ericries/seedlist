## About

Meticulous is a San Francisco–based developer-tools startup that builds automated software testing infrastructure aimed at helping engineering teams verify code changes before deployment [^1][^2]. The company was founded in 2021 by brothers Gabriel Spencer-Harper and Quentin Spencer-Harper [^2]. Meticulous records application interactions and uses AI to generate and maintain end-to-end tests covering user workflows and edge cases; the platform currently focuses on frontend testing with expansion plans for backend and performance testing [^2].

On 2026-07-15 Meticulous announced a $15 million Series A led by Chemistry, with participation from Menlo Ventures and angel investors from companies including Poolside, Dropbox, Vercel, OpenAI, Stripe, Adobe, Hex, and Cursor [^1][^2][^3]. The round is intended to accelerate deployment of AI-generated code by helping developers "trust and ship AI-generated code faster" [^2].
