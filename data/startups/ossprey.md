## About

Ossprey is a UK-based cybersecurity startup founded in 2026 by Nate Dunning (CEO) and David Read. The company builds software supply chain security tools that detect malicious code in open-source software before it reaches production environments [^1] [^2].

## What Investors Say

> "Open-source software supply chain attacks have quietly exploded in scale and sophistication, yet security tools today can't tell malicious code from benign." — Millan Suri, Episode 1 Ventures, July 2026 [^3]

## What Founders Say
