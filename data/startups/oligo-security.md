## About

Oligo Security is a Tel Aviv-based cybersecurity company that builds runtime security across applications, cloud workloads, and AI systems. Its platform combines deep runtime visibility with real-time protection, observing code execution as it happens to block exploit attempts without breaking production and to filter vulnerability noise [^1][^2]. Over the past year, Oligo reported 300% year-over-year growth in annual recurring revenue and more than doubled its valuation since its Series B [^1]. The company was selected by AWS as an exclusive AI runtime security partner for AWS Security Hub Extended and joined Palantir's FedStart Program to accelerate its path to FedRAMP High and DoD Impact Level 5 (IL5) authorization [^1][^2].
