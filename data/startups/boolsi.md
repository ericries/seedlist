## About

BoolSi is a Boston-based startup that develops a compiler which converts standard software code written in C, C++, and other high-level languages into custom hardware circuits optimized for FPGAs (field-programmable gate arrays) [^1][^2]. The technology uses machine-learning models to transform hot functions in software into digital circuits that can be deployed as hardware accelerators — the company demonstrates a regex routine running approximately 63 times faster on a custom circuit versus a traditional CPU [^1]. BoolSi plans to open a private beta in the third quarter of 2026 [^1][^2].
